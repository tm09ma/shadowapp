# Shadow Tracker v2

## Backend starten
1. IntelliJ: Ordner `backend` oeffnen
2. Gradle JVM = Java 21 (Settings > Build Tools > Gradle)
3. Run-Konfig Environment: DB_URL, DB_USER, DB_PASSWORD, ANTHROPIC_API_KEY
4. ShadowTrackerApplication starten -> http://localhost:8080

## Frontend starten
1. cd frontend
2. npm install
3. npm start -> http://localhost:4200

Backend muss laufen bevor Frontend genutzt wird.
